# Tasks Manager

Allows for tracking tasks, it's assignees and deadlines with web interface and personal list of tasks for each account.

### Prerequisites

See requirements.txt

### Installing

1. Run migrations using the command "python manage.py migrate".
2. Then you should be able to "python manage.py runserver".

## Built With

* [Django] - Web framework used here
* [Rocket Django](https://github.com/app-generator/rocket-django) - Open-source Django Starter
